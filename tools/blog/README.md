# Blog tooling

Posts live at `/blog/<slug>/index.html` and share `/blog/blog.css`. New posts are built from `_template.html`
(replace every `{{PLACEHOLDER}}`; the writer brief with the voice rules and product facts is in the Operating Manual).
After adding a post: add it to `/blog/index.html` (cards + ItemList JSON-LD), `/sitemap.xml` and `/llms.txt`.
